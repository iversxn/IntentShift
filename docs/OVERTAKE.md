## Title

IntentShift - Adaptive Automatic Gearbox

## Version

1.0.0

## Short description

A lightweight CSP Lua app that delivers adaptive, keyboard-free automatic
shifting for Assetto Corsa.

## Description

IntentShift replaces fixed-RPM automatic shifting with a responsive controller
that follows how you drive. It continuously evaluates throttle demand, braking,
engine speed and wheel slip, then selects a shift point suited to the moment.

Choose Cruise for relaxed free-roam driving, Road for a balanced everyday feel,
or Sport for stronger gear hold and quicker kickdown. Manual mode returns full
shift control without unloading the app.

Shifts are sent through CSP's native car-control API. IntentShift does not fake
keyboard presses, requires no P/O bindings, and cannot activate unrelated
keyboard commands.

### Features

- Three distinct automatic profiles: Cruise, Road and Sport
- Adaptive upshift points based on live driver demand
- Kickdown and braking-aware downshifts
- Wheel-slip protection
- Anti-hunting and rapid-reversal guards
- Automatic calibration to each car's idle speed and rev limiter
- Persistent profile selection
- Compact live telemetry panel

### Requirements

- Assetto Corsa on PC
- Custom Shaders Patch 0.3.0-preview581 or newer
- Content Manager recommended

### Installation

Drag the downloaded ZIP into Content Manager and install it. Disable the game's
built-in automatic shifting and other gearbox automation apps. In a driving
session, open IntentShift from the app sidebar and select a profile.

Sequential and paddle-shift cars are recommended. Cars with unusual drivetrains
or custom transmission scripts may behave differently.
